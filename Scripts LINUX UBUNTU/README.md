# Scripts Linux — Automação e Administração Básica

Coleção de scripts Bash simples, escritos durante o estudo de administração de sistemas Linux/Ubuntu.

## Conteúdo

| Script | O que faz |
|---|---|
| `Backup(Script).txt` | Compacta um diretório em `.tar.gz` com timestamp no nome do arquivo |
| `Compactador(Script).txt` | Compacta uma lista de arquivos/pastas recebida por parâmetro |
| `Monitoramento Nginx.txt` | Verifica se o processo do Nginx está ativo e registra o horário da checagem |
| `Verifica existencia de arquivos.txt` | Pergunta o nome de um arquivo e informa se ele existe no diretório atual |
| `criador de diretorio.txt` | Cria um diretório a partir do nome informado pelo usuário |
| `contador_1_a_5.txt` | Exercício de laço `for` — imprime números de 1 a 5 |
| `Mensagem de boas vindas.txt` | Script de exemplo mínimo, usado como primeiro teste |

## Por que este repositório existe

Assim como a pasta de estudos em Python, estes são exercícios de prática de shell script — não projetos finalizados. Servem como registro de evolução no aprendizado de automação e administração básica em Linux.

**Nota:** os arquivos estão como `.txt` para facilitar a visualização direta no GitHub; para executar, renomeie para `.sh` e dê permissão de execução (`chmod +x arquivo.sh`).
